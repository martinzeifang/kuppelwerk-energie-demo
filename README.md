# Kuppelwerk Energie AG — Demo-Repository

> **Alles in diesem Repository ist erfunden.**
> Die Kuppelwerk Energie AG existiert nicht. Produkt, Schwachstellen,
> Prüfberichte, Versionen und Datumsangaben sind für eine Produktvorführung
> der **AI Compliance Suite** erdacht. Keine der hier beschriebenen
> Schwachstellen betrifft ein reales Produkt, und keine Aussage hier ist eine
> Sicherheitsmeldung über ein reales Unternehmen.

## Wozu dieses Repository

Die AI Compliance Suite kann an jedem Objekt — Anforderung, OWASP-Kontrolle,
Risiko, Schwachstelle, WiBA-Prüffrage — ein GitHub-Issue anlegen, es
überwachen und seinen Inhalt zurück in die Akte übernehmen. Dieses Repository
ist das Gegenstück dazu: Hier entstehen die Issues, die in der Vorführung mit
den Vorgängen der Suite verknüpft werden.

## Woran man die Issues erkennt

Jedes Issue trägt ein Label, das sagt, aus welchem Modul es kommt:

| Label | Herkunft in der Suite |
|---|---|
| `cra-anforderung` | CRA-Anforderung (Verordnung (EU) 2024/2847) |
| `owasp-control` | OWASP Proactive Control |
| `schwachstelle` | Eintrag im Schwachstellenregister |
| `risiko` | Risiko aus der Risikobewertung |
| `nis2` | NIS-2-Anforderung (Art. 21) |
| `dsgvo` | Datenschutz-Maßnahme |
| `wiba` | BSI-WiBA-Prüffrage |
| `pentest` | Befund aus dem Penetrationstest |
